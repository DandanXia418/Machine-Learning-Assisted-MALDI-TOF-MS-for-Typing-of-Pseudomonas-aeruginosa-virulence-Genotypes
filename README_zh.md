# 代码使用说明

本仓库用于复现铜绿假单胞菌毒力基因全景筛查及 MALDI-TOF 预测 WGS 定义的 `exoU-only`/`exoS-only` T3SS 基因型。

研究终点是**基因携带状态**，不是基因表达，也不是直接检测 ExoU 或 ExoS 蛋白。两个中心都参与了前期终点筛选和方法开发，因此正文应将双中心结果称为“跨中心泛化分析”，不应称为完全独立、前瞻性外部验证。

正式分析坚持以下规则：以菌株为统计单位；同一菌株的10张技术重复谱不跨折；特征筛选只在训练折完成；报告两个跨中心方向；主终点模型固定为两个 RBF-SVM 的等权集成；同时报告阴性结果、谱系阻断验证和阈值平台偏移。

GitHub 中不要上传患者姓名、住院号、病历号、出生日期、临床自由文本或原始医院 Excel 表。大体积 `.npy` 矩阵建议放在受控数据仓库、Zenodo/OSF 数据附件或 GitHub Release，并在 `config.yml` 中填写下载后的相对路径。

运行顺序、环境配置和输入格式见英文 [README](README.md) 与 [data/README.md](data/README.md)。
